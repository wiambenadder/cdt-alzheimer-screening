# Videos

Place the two required videos here:

- `demo.mp4` - 3 to 5 minute pitch for a non-technical audience. No code shown.
  Tell the story: what is the CDT, why does it matter, what does the system
  do, show it running, show the best results.

- `technical_walkthrough.mp4` - 5 to 10 minute walkthrough for an ML engineer.
  Walk through the code organization, explain the ML techniques used
  (especially how ViT's self-attention works - this hits rubric item #97),
  point at concrete rubric items, discuss what was hard.

Both videos should also be uploaded to YouTube / Google Drive / similar and
**linked prominently** in the top-level `README.md` under the Video Links
section. The handout says: "These videos should be stored in your repository
and clearly linked in your README file."

Recording tips:
- Use a free tool like OBS Studio, QuickTime, or Loom
- 1080p is plenty, 720p is acceptable
- Voice + screen share works; a talking-head overlay is not required
- Run through your slides / demo once before recording to keep within the
  time limits - under 5 min for demo, under 10 min for walkthrough
- Do not exceed the time limits; the rubric asks specifically for
  "correct length"
